# TRAVELY

Стартова основа сайту на React, TypeScript і Vite. Інтерфейс та підписи — українською.

## Запуск

Запускайте команди з папки `frontend/`:

```bash
npm install
npm run dev
```

Для перевірки production-збірки виконайте `npm run build`, а для локального перегляду готової збірки — `npm run preview`.

Серверну частину Django буде розміщено окремо в `../backend/`.

## Структура проєкту

```text
src/
  app/                         # Збірка сторінки та глобальні стилі
  shared/ui/                   # Повторно використовувані SVG-компоненти
  features/
    destination-search/        # Пошук напрямку та його фонове зображення
    hero/                      # Головний банер та його зображення
    site-footer/               # Нижня частина сторінки
    site-header/               # Шапка сайту та навігація
    travel-inspiration/        # Блок натхнення та його зображення
  main.tsx                     # Точка входу React
```

Кожна функціональна секція має власний компонент і CSS-файл. Її зображення зберігайте поруч у папці `assets` цієї секції. Спільні компоненти, як-от SVG-логотип і векторні іконки, розміщуйте в `src/shared/ui/`; не підміняйте іконки текстовими символами. Для нового блоку створіть `src/features/new-feature/` з компонентом `NewFeature.tsx`, стилями `NewFeature.css` та за потреби папкою `assets/`. Потім додайте компонент у `src/app/App.tsx`.

Компоненти пишемо в PascalCase, назви директорій feature — у kebab-case. Глобальні стилі й CSS-змінні живуть у `src/app/global.css`; стилі окремої секції — поруч із її компонентом.

Фотографії секцій і футера імпортовані з [макета Figma](https://www.figma.com/design/YE32JMSfThr5XJN6zfda6P/%D0%BD%D0%BE%D0%B2%D1%8B%D0%B9-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82?node-id=4046-31) та оптимізовані у формат WebP. У блоці натхнення фото неба й прозорий силует Пізанської вежі — окремі файли, зібрані шарами в компоненті. Не використовуйте скриншоти фреймів як зображення сторінки: фото зберігайте окремими файлами в `assets`, а текст, елементи форм і декоративну графіку створюйте компонентами та стилями.

Шрифт Manrope підключено локально через `@fontsource-variable/manrope`, щоб він стабільно відображався без зовнішнього запиту до Google Fonts.
