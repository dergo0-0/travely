# TRAVELY

Репозиторій підготовлено для окремих частин застосунку:

- `frontend/` — клієнтська частина на React, TypeScript і Vite.
- `backend/` — порожня папка для майбутнього Django-проєкту.

## Початок роботи

```bash
cd frontend
npm install
npm run dev
```

Структуру feature-based секцій, правила для компонентів і зображень та інші команди дивіться у [посібнику frontend](./frontend/README.md).
