# TRAVELY

Фронтенд Travely — React, TypeScript і Vite. Актуальний бекенд для JWT, локацій, постів і фото міст зберігається окремо в [`alka-Ukraine/python`](https://github.com/alka-Ukraine/python). Папка `backend/` у цьому репозиторії — попередня локальна копія; нові API треба запускати з окремого репозиторію.

## Локальний запуск

1. Клонуйте бекенд `alka-Ukraine/python`. У його папці скопіюйте `.env.sample` у `.env`, задайте `DJANGO_SECRET_KEY` та запустіть `make up` (або `docker compose up --build -d`). API буде на `http://localhost:8000/api/`, Swagger — на `http://localhost:8000/swagger/`.
2. У `frontend/` скопіюйте `.env.example` у `.env`, виконайте `npm ci` та `npm run dev`. Відкрийте адресу, яку виведе Vite, зазвичай `http://localhost:5173/`.

Vite проксирує `/api` та `/media` до бекенду на порту 8000. Для віддаленого бекенду задайте `API_PROXY_TARGET` та `LOCATIONS_API_TARGET` в `frontend/.env`. Для прямого доступу з браузера використовуйте `VITE_API_BASE_URL=https://ваш-бекенд/api` і дозвольте адресу фронтенду в CORS бекенду.

## Пости й фото міста

Пошук веде на підбірку міста. Пости можна читати без входу. Якщо для міста немає постів і головного фото, сторінка пропонує реєстрацію. Після входу користувач може створювати й редагувати власні пости, а також додати головне фото, якщо його ще немає. Фото можна оновити лише його автору. Пости відкриваються окремою сторінкою.

Для локальної перевірки цих можливостей потрібна версія окремого бекенду з маршрутами `/api/city-posts/` і `/api/city-covers/`. Якщо їх ще немає на сервері, інтерфейс чесно покаже помилку завантаження; реєстрація та збереження матеріалів теж не працюватимуть до оновлення бекенду.
